# Trailhead 🏔

The Ross family everything-app: a single-file PWA that starts at the trailhead and grows — workouts and interval timers today, grocery and house maintenance next.

- **Workout**: a program-driven training calendar (6-week build + deload), tap-to-log strength sessions with weights pre-filled from your last workout, and one-tap edit mode when life rearranges the week.
- **Timers**: a repeating beeper and an A/B interval timer for the gym floor.
- Vanilla JS, no build step, offline-first via localStorage, optional household cloud sync via Supabase.

Made for two people who like mountains.
